# Assignment 3 题目描述

## Problem 1: 固定长度子数组重复元素检测

给定整数数组nums和整数k，判断是否存在长度恰好为k的连续子数组包含至少两个相同元素。

**输入输出方式：**
输入：根据提示输入数组个数和数组各元素，然后输入`k`
输出：判断是否存在长度恰好为k的连续子数组包含至少两个相同元素对应输出"true"/"false"
示例：
输入：
``` 
6
1 2 3 2 4 5
3
```
输出：
```
true
```

**解法**：使用滑动窗口+哈希表统计窗口内元素频率，时间复杂度O(n)。

## Problem 2: 索引和值双重约束的元素对查找

给定整数数组nums和两个整数k、t，判断是否存在两个不同索引i和j满足：
- 索引距离：`abs(i - j) <= k`
- 值差距：`abs(nums[i] - nums[j]) <= t`

输入：先输入数组大小，然后输入数组中各个元素，然后输入k和t
输出：判断是否存在满足条件，输出"true"/"false"
示例：
输入：
```
5
1 5 9 3 1
2 2
```
输出
```
true
```

**解法**：使用有序集合(std::set)维护滑动窗口，利用二分查找检测值范围，时间复杂度O(n log k)。

## Problem 3: 最大长度内的频率达标检测

给定整数数组nums和两个整数k、f，判断是否存在长度不超过k的连续子数组，其中某个元素出现至少f次。

输入：先输入数组大小，然后输入数组中各个元素，然后输入k和t
输出：判断是否存在满足条件，输出"true"/"false"
示例：
输入：
```
6
1 2 2 3 2 4
4 3
```
输出
```
true
```
**解法**：使用滑动窗口+频率统计，动态维护窗口内最大出现次数，找到满足条件的最短窗口。
