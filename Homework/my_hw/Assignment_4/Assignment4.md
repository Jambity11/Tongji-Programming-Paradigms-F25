# 习题1
设计一个名为`BankAccount`的类，用于模拟简单的银行系统。每个账户应包含以下信息：
- 账户名（默认值："anonymous"）
- 账户余额（默认值：0.0）
- 账户类型（“储蓄账户”或“活期账户”，默认值："saving"，即“储蓄账户”）

该类需支持以下操作：
1. `deposit(amount)`——将指定金额添加到账户余额中。
2. `withdraw(amount)`——从账户余额中提取指定金额；若余额不足，需显示警告信息。
3. `display()`——打印或返回账户的所有详细信息（账户名、余额、账户类型）。
4. 相等性测试（`==`）——若两个账户属于同一账户名，则返回`True`。
5. 不等性测试（`!=`）——若两个账户属于不同账户名，则返回`True`。

系统中可同时存在多个“匿名账户”（账户名为"anonymous"），但这些账户的余额和交易记录必须完全独立。


# 习题2
实现一个名为`Vector3D`的类，用于表示三维浮点型向量。

该类需提供以下功能：
1. 构造函数：
   - 默认构造函数：从标准输入中读取三个值来初始化向量。
   - 另一个构造函数：接收一个长度为3的数组来初始化向量。
2. 成员函数：
   - `add(const Vector3D& v)`——返回当前向量与向量`v`的和（向量加法结果）。
   - `dot(const Vector3D& v)`——返回当前向量与向量`v`的点积。
   - `cross(const Vector3D& v)`——返回当前向量与向量`v`的叉积。
   - `print()`——以`(x, y, z)`的格式打印向量（`x`、`y`、`z`分别为向量的三个分量）。
3. 运算符重载：
   - `operator+`——重载加法运算符，实现向量加法。
   - `operator-`——重载减法运算符，实现向量减法。
   - `operator*`——重载乘法运算符，实现标量乘法（向量与标量的乘法）。
   - `operator+=`——重载复合赋值运算符，将另一个向量的值加到当前向量上。
   - `operator[](int index)`——重载下标运算符，实现对向量`x`、`y`、`z`三个分量的下标访问。对于非`const`对象，返回`float&`（引用）；对于`const`对象，返回`float`（值）。

注意：每个向量的分量（`x`、`y`、`z`）必须相互独立（一个分量的修改不影响其他分量）。

# 习题6 支持自定义比较的通用最小值查找器
## 题目描述
设计一个函数模板`findMin`，用于查找三个给定值中的最小值（支持多种数据类型）。若多个值同为最小值，则函数应返回最后一个最小值。

该函数需支持以下数据类型：
- `int`（整型）
- `double`（双精度浮点型）
- `char`（字符型）
- `string`（字符串型，规则：长度较短的字符串为较小值）
- `Point`结构体（包含`int`类型的`x`和`y`成员，规则：欧几里得距离较小的`Point`对象为较小值）
- `Point*`（`Point`类指针，规则：通过解引用指针获取`Point`对象后，按`Point`对象的比较规则进行比较）

## 示例输入
1 2 3  
1.3 2.4 0.6  
a b c  
hello hi he  
1,2 3,4 0,1  
1,2 0,1 3,4  

## 示例输出
1  
0.6  
a  
he  
0,1  
0,1  

## 提示
定义`Point`结构体如下：
```cpp
struct Point {
    int x, y;
    double dist() const;  // 用于计算欧几里得距离
};
```
可通过重载`operator<`（小于运算符）或为函数模板重载自定义比较逻辑来实现需求。
