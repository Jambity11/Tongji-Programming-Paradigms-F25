# 输入输出规则
# Problem 1
输入一个字符串
示例：
input:
``` 
sunday
```
output:
```
saddas
```

# Problem 2
输入一个整数`n`(1 <= n <= 10)
input:
```
1
```
output:
```
5
```

# Problem 4

# Problem 5
依次输入两个数
input:
```
23 456
```
output:
```
10488
```
